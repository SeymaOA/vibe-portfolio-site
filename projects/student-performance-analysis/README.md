# Student Performance Analysis

A beginner-friendly Python data analysis project built in Jupyter Notebook.

## Goal

Analyze student performance data and explore which habits are connected with higher science scores.

## Questions

- Do study hours relate to science scores?
- Does attendance help explain pass/fail outcomes?
- Can a simple model predict whether a student passed?

## Tools

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Files

- `student_performance_analysis.ipynb` - main notebook
- `data/student_performance.csv` - sample dataset

## How to Run

Open the notebook in Jupyter and run the cells from top to bottom.

```powershell
jupyter notebook student_performance_analysis.ipynb
```
